# PR #101: первые пункты списка доступны указателю

05.11.2026. Исходный коммит PR: `b7a9be25d3b0717aa6fe098b0101d41fb7ae09f7`.

## Причина и исправление

Кнопки формы с `z-30` перекрывали первые пункты всплывающего списка с `z-index: 20`. После поиска единственный нужный вариант оказывался под кнопками. Предыдущие сценарии проверяли кнопку отмены при открытом списке, но не выбор первого варианта.

Добавлен необязательный `side="top"` в SearchPicker. Его используют только «Функциональный руководитель» и «Подразделение выше» в структуре. Список раскрывается над полем, высота ограничена свободным местом внутри диалога; ограничение пересчитывается при прокрутке диалога и изменении размера окна. Кнопки больше не поднимаются над списком. Остальные поля сохраняют прежнее поведение.

Выбран локальный способ устранить блокер. Перевод всех списков в портал остаётся отдельной работой; существующие ограничения inline не сняты.
