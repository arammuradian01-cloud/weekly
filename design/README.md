# Дизайн

`ds-step-1/`: дизайн-система «Сравни: внутренние продукты» от Claude Design, шаг Д1, версия 08.10.2026 (сверена с брендбуком и стендом). Токены светлой и тёмной темы, 100+ компонентов на plain React без сборки, карточки состояний, официальный логотип, записка с решениями, таблица токенов для разработки. Папки uploads и screenshots сюда не копируются: в них брендбук и рабочие файлы с персональными данными.

Перенесена в продукт на этапе 18: токены в `src/styles/tokens.css`, Tailwind читает их через `src/app/globals.css`, подробности в хэндоффе этапа 18. Этот пакет остаётся эталоном вида.

Экраны (шаг Д2) появятся рядом, когда их сделают.
