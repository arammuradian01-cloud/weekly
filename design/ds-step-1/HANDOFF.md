# Передача в разработку: дизайн-система «Сравни: внутренние продукты»

Пакет для этапа 18 (новый дизайн ставится в код одним заходом).

## Что внутри
- `styles.css` подключает всё: шрифты, токены (`tokens/`), базовые правила, стили компонентов (`components/components.css`).
- `tokens/colors.css`: CSS-переменные светлой темы на `:root`, тёмной на `[data-theme="dark"]`. Имена совпадают с `guidelines/tokens-table.md` (там же имена для @theme Tailwind 4 и соответствие токенам этапа 10).
- `tokens/typography.css`: шкала ноутбука по умолчанию, телефон через медиазапрос или `data-scale="phone"`, проектор через `data-scale="projector"`.
- `tokens/shape.css`: радиусы, тени, отступы, размеры, сетка, фокус, движение.
- `components/<группа>/*.jsx`: React-компоненты без сборки (plain JS, props описаны в комментарии сверху и в `.d.ts`). CSS каждой группы рядом (`core.css`, `forms.css`, `navigation.css`, `layout.css` и т. д.), классы с префиксом `sv-`.
- `components/*/**.card.html`: карточки-примеры, открываются в браузере, показывают все состояния в двух темах. Это эталон вида.
- `assets/logo/`: официальный логотип из брендбука (rus/eng, цветной, белый, монохром). Не перерисовывать.
- `guidelines/zapiska.md`: принятые решения и открытые вопросы. `readme.md`, `SKILL.md`: правила использования.
- `index.html`: обзор всей системы.

## Источники стиля
- Брендбук «Руководство по фирменному стилю» (Digital guide 2021): основные цвета, Aeroport, логоблок, радиусы кнопок. Текстовая выжимка: `guidelines/brandbook-text.txt`, разбор: `guidelines/brandbook.card.html` и раздел в `guidelines/zapiska.md`.
- CSS sravni.ru (06.10.2026): статусные цвета, тёмная тема, тени, движение.
- Скриншоты стенда Weekly (07.10.2026): структура экранов, компоненты «Тестовый стенд», TeamTable, DeadlineRow.

## Как переносить в код
1. Скопировать `tokens/` и подключить переменные; класс темы: атрибут `data-theme="dark"` на `html`.
2. Иконки: Lucide, размер 20, обводка 1,5 (`components/core/Icon.jsx`).
3. Компоненты переносить по группам, имена сохранять как в файлах (Button, Input, TaskTable, AppShell и т. д.).
4. Адаптив оболочки через container queries (`.sv-shell-root`), точки 1260, 1024, 768.
5. Шрифт Aeroport Bold подключить через @font-face в `tokens/fonts.css`, когда бренд-команда даст файл; до этого Golos Text Bold.
