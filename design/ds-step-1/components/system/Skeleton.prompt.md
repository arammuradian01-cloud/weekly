Скелетоны загрузки: строка (SkeletonRow), карточка (SkeletonCard), текст (Skeleton). Движение отключается при уменьшении движения.

```jsx
import { Skeleton, SkeletonRow, SkeletonCard } from './Skeleton.jsx';

<Skeleton />
```

Экспорты: Skeleton, SkeletonRow, SkeletonCard. Стили: классы `sv-*` в `components/system/system.css`, значения только из токенов `styles.css`. Все тексты на русском, на «вы», глагол в начале кнопки, без восклицательных знаков.
