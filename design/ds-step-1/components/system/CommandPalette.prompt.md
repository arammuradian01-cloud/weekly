Командная строка Cmd+K: поиск по задачам, записям, решениям и людям; быстрые действия с подсказкой клавиш. Результаты сгруппированы по типу. groups: [{ name, items: [{ key, label, sub, icon, person, hotkey }] }]. query, activeKey.

```jsx
import { CommandPalette } from './CommandPalette.jsx';

<CommandPalette />
```

Экспорты: CommandPalette, CMDK_ACTIONS. Стили: классы `sv-*` в `components/system/system.css`, значения только из токенов `styles.css`. Все тексты на русском, на «вы», глагол в начале кнопки, без восклицательных знаков.
