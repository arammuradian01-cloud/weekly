Полоса истории статусов в карточке задачи: сколько дней задача была в каждом статусе. segments: [{ status, days }].

```jsx
import { StatusHistoryBar } from './StatusHistoryBar.jsx';

<StatusHistoryBar />
```

Экспорты: StatusHistoryBar. Стили: классы `sv-*` в `components/tasks/tasks.css`, значения только из токенов `styles.css`. Все тексты на русском, на «вы», глагол в начале кнопки, без восклицательных знаков.
