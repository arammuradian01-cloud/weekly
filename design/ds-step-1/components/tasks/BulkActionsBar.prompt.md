Панель массовых действий при выборе строк: залипает снизу. actions: [{ key, label, icon, danger }].

```jsx
import { BulkActionsBar } from './BulkActionsBar.jsx';

<BulkActionsBar />
```

Экспорты: BulkActionsBar. Стили: классы `sv-*` в `components/tasks/tasks.css`, значения только из токенов `styles.css`. Все тексты на русском, на «вы», глагол в начале кнопки, без восклицательных знаков.
