Подсказка: тёмная плашка, одна фраза, иногда с клавишей. Появляется при наведении и фокусе на обёрнутом элементе. staticTip: показать сразу (для макетов).

```jsx
import { Tooltip } from './Tooltip.jsx';

<Tooltip />
```

Экспорты: Tooltip. Стили: классы `sv-*` в `components/overlays/overlays.css`, значения только из токенов `styles.css`. Все тексты на русском, на «вы», глагол в начале кнопки, без восклицательных знаков.
