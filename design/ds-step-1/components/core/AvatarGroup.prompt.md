```jsx
import { AvatarGroup } from './AvatarGroup.jsx';

<AvatarGroup />
```

Экспорты: AvatarGroup. Стили: классы `sv-*` в `components/core/core.css`, значения только из токенов `styles.css`. Все тексты на русском, на «вы», глагол в начале кнопки, без восклицательных знаков.
