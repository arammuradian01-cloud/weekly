Срок задачи. Просрочка: красная подпись «просрочена на N дн.». soon: срок сегодня или завтра.

```jsx
import { daysWord, OverdueLabel } from './OverdueLabel.jsx';

<OverdueLabel />
```

Экспорты: daysWord, OverdueLabel. Стили: классы `sv-*` в `components/core/core.css`, значения только из токенов `styles.css`. Все тексты на русском, на «вы», глагол в начале кнопки, без восклицательных знаков.
