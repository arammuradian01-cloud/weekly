Метка статуса: слово всегда рядом с цветом. tone: success, warning, danger, info, accent, neutral, outline (Предложена), brand. dot: точка; half: половинная точка (Частично).

```jsx
import { StatusBadge } from './StatusBadge.jsx';

<StatusBadge />
```

Экспорты: StatusBadge, TASK_STATUS, WEEKLY_STATUS, REQUEST_STATUS. Стили: классы `sv-*` в `components/core/core.css`, значения только из токенов `styles.css`. Все тексты на русском, на «вы», глагол в начале кнопки, без восклицательных знаков.
