Кнопка-иконка. Обязателен label (читается вслух и показывается как подсказка). size: md 44, sm 36, xs 28.

```jsx
import { IconButton } from './IconButton.jsx';

<IconButton />
```

Экспорты: IconButton. Стили: классы `sv-*` в `components/core/core.css`, значения только из токенов `styles.css`. Все тексты на русском, на «вы», глагол в начале кнопки, без восклицательных знаков.
