Аватар с инициалами на спокойном круге. Цвет выбирается по имени, фотографий нет. size: xs 20, sm 24, md 32, lg 40, xl 56. status: точка weekly (success, warning, danger, neutral, accent). vacancy: пустой пунктирный круг.

```jsx
import { initialsOf, toneOf, Avatar } from './Avatar.jsx';

<Avatar />
```

Экспорты: initialsOf, toneOf, Avatar. Стили: классы `sv-*` в `components/core/core.css`, значения только из токенов `styles.css`. Все тексты на русском, на «вы», глагол в начале кнопки, без восклицательных знаков.
