Столбики и линия по неделям. data: [{ label, bar, line, current }]. insight: одна фраза с выводом. barLabel, lineLabel: легенда. max: верх шкалы.

```jsx
import { BarLineChart } from './BarLineChart.jsx';

<BarLineChart />
```

Экспорты: BarLineChart. Стили: классы `sv-*` в `components/charts/charts.css`, значения только из токенов `styles.css`. Все тексты на русском, на «вы», глагол в начале кнопки, без восклицательных знаков.
