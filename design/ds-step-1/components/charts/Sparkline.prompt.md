Мини-график в карточке лидера: линия по последним неделям, текущее значение и изменение. values: числа; trend: up | down | flat (цвет линии).

```jsx
import { Sparkline } from './Sparkline.jsx';

<Sparkline />
```

Экспорты: Sparkline. Стили: классы `sv-*` в `components/charts/charts.css`, значения только из токенов `styles.css`. Все тексты на русском, на «вы», глагол в начале кнопки, без восклицательных знаков.
