Полоса прогресса цели: база, текущее, целевое; отметка плана. tone: ok, risk, fail или по умолчанию акцент. Значения метрик живут в борде, здесь только показ.

```jsx
import { GoalProgress } from './GoalProgress.jsx';

<GoalProgress />
```

Экспорты: GoalProgress. Стили: классы `sv-*` в `components/charts/charts.css`, значения только из токенов `styles.css`. Все тексты на русском, на «вы», глагол в начале кнопки, без восклицательных знаков.
