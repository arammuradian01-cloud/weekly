Полоса из семи дней недели и две ячейки: срок weekly и встреча. days: [{ wd, n, today, past, weekend, mark: { kind: 'deadline' | 'meeting', label } }]. По умолчанию неделя 41, 05.10-11.10.2026, сегодня среда 07.10.

```jsx
import { WeekDays } from './WeekDays.jsx';

<WeekDays />
```

Экспорты: WeekDays. Стили: классы `sv-*` в `components/weekly/weekly.css`, значения только из токенов `styles.css`. Все тексты на русском, на «вы», глагол в начале кнопки, без восклицательных знаков.
