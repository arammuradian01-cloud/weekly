Индикатор для участника: «Вы смотрите пункт ведущего» или «Вы отошли» с кнопкой «Вернуться к ведущему».

```jsx
import { FollowingIndicator, MeetingBar, MeetingKeys } from './FollowingIndicator.jsx';

<FollowingIndicator />
```

Экспорты: FollowingIndicator, MeetingBar, MeetingKeys. Стили: классы `sv-*` в `components/meeting/meeting.css`, значения только из токенов `styles.css`. Все тексты на русском, на «вы», глагол в начале кнопки, без восклицательных знаков.
