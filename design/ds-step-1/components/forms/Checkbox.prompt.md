Чекбокс: рамка D40 (1,5 px), отмеченный с заливкой акцента и тёмной галочкой. indeterminate для «выбраны не все».

```jsx
import { Checkbox, Radio } from './Checkbox.jsx';

<Checkbox />
```

Экспорты: Checkbox, Radio. Стили: классы `sv-*` в `components/forms/forms.css`, значения только из токенов `styles.css`. Все тексты на русском, на «вы», глагол в начале кнопки, без восклицательных знаков.
