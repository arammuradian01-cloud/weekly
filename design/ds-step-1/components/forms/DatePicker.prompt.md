Выбор даты с быстрыми вариантами: завтра, пятница, через неделю. value: Date или null. open: открыт для макета. marked: даты с отметкой (срок weekly, встреча).

```jsx
import { formatDate, DatePicker } from './DatePicker.jsx';

<DatePicker />
```

Экспорты: formatDate, DatePicker. Стили: классы `sv-*` в `components/forms/forms.css`, значения только из токенов `styles.css`. Все тексты на русском, на «вы», глагол в начале кнопки, без восклицательных знаков.
