Многострочное поле. Счётчик знаков идёт через FormField (max, count): «Что произошло» до 150, «Подробнее» до 1000.

```jsx
import { Textarea } from './Textarea.jsx';

<Textarea />
```

Экспорты: Textarea. Стили: классы `sv-*` в `components/forms/forms.css`, значения только из токенов `styles.css`. Все тексты на русском, на «вы», глагол в начале кнопки, без восклицательных знаков.
